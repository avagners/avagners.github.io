# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — по [семантическому версионированию](https://semver.org/lang/ru/).
Текущая версия сайта лежит в файле `VERSION` и показывается в подвале страниц.

## [1.0.1] — 2026-11-09

### Изменено

- На главной уточнена формулировка: «работал в роли инженера данных»
  вместо «работал с данными как инженер»

## [1.0.0] — 2026-11-09

Блог запущен: посты пишутся в Obsidian, собираются в статический HTML.

### Добавлено

- Страница постов `/posts.html` и первый пост «Зачем этот блог»
- Конвертер Markdown → HTML: `scripts/build_posts.py` (frontmatter, статусы,
  заголовки, списки, код, цитаты, ссылки)
- Тизеры для Telegram и VK: `scripts/make_teaser.py`
- OG-теги, `description` и `canonical` на страницах постов
- Страница «Сотрудничество» с призывом и контактами
- Версия сайта в подвале, этот CHANGELOG и скрипт `scripts/bump_version.py`

### Изменено

- Главная и «Сейчас»: роль разработчика дата-платформы, MCP-хаб, 3,5 года в банке
- Стек: Python, SQL, Airflow, Trino, Spark, Hadoop, REST, MCP
- Заглушка «Donate» в навигации заменена пунктом «Контакты»
- Внутри постов выровнены отступы: вместо двойных браузерных у `pre` и `blockquote`
  действует единый ритм

### Исправлено

- Битая ссылка на иконку Airflow и незакрытый тег `<a>` в профильном README

## [0.1.0] — 2026-01-14

### Добавлено

- Начальная версия сайта: главная страница, «Сейчас», стили, контакты в подвале
